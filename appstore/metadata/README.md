# Métadonnées App Store – Tarikh

Textes de la fiche App Store pour 6 langues (fr, en, ar, es, id, ur). Un dossier par langue, fichiers en texte brut UTF-8, sans saut de ligne final.

## Fichiers

- `name.txt` : nom de l'app (30 caractères max)
- `subtitle.txt` : sous-titre (30 max)
- `promotional_text.txt` : texte promotionnel (170 max)
- `description.txt` : description (4000 max, cible 1800–2600)
- `keywords.txt` : mots-clés séparés par des virgules, sans espace (100 max, virgules comprises)
- `whats_new.txt` : nouveautés de la version
